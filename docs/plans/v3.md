# Tailmon v0.3.0 — implementation plan (approved by owner 2026-11-07)

Visual reference: `docs/plans/v3-mockup.html` (open in a browser; the "Yeni" tab is the
approved design). UI strings are Turkish, exactly as in the mockup.

Hard rules (unchanged from v2, do not break):
- Read-only. No power controls, no kill.
- Bounded memory: no history buffers. Keeping ONE previous counter snapshot per host
  (for rates) and a small persisted last-known-disk map is allowed.
- Agent samples on demand only; no background tickers.
- `go test ./...` (incl. soak test) must pass. Swift tests must pass.
- Do NOT touch the Windows box (barathans-5090) or tahalinux. Do not reboot anything.
- Work on a local branch `v3`; commit locally, do not push.

## 1. Go agent

1. **Lite vs full sample.** `GET /stats?lite=1` returns cpu, mem, gpu, disks, net,
   disk_io, uptime, agent — NO process enumeration. Default `/stats` (and `?top=N`)
   stays full and backward compatible. Separate 1s single-flight caches for lite/full.
   Lite CPU% = delta of `cpu.Times` vs the previous lite/full call's counters (keep
   one previous value); if none or older than 60s, use a 250ms window.
2. **macOS: 3 subprocesses → 1.** GPU name via `unix.Sysctl("machdep.cpu.brand_string")`
   once (sync.Once). Memory pressure via `unix.SysctlUint32("kern.memorystatus_level")`
   (= free %, same buckets as now) instead of spawning `memory_pressure`. Keep `ioreg`.
   From the same ioreg output also parse `"In use system memory"` (bytes) →
   GPU `vram_used_mb`, `vram_total_mb` null, new `unified: true`.
3. **nvidia-smi**: same single call, add `power.draw,power.limit,fan.speed`
   → new GPU fields `power_w`, `power_limit_w`, `fan_pct` ("[N/A]" → null). Update
   parser + tests.
4. **Agent priority**: lower own priority at start (Windows BELOW_NORMAL_PRIORITY_CLASS
   via x/sys/windows; unix `setpriority` +10). Training on the box must never compete.
5. **Disks — all real volumes.** Disk gets additive fields `label`, `fstype`, `kind`
   (internal | external | removable | network), `used_gb`.
   - macOS: root reported as mount "/" with label "HD", usage from
     `/System/Volumes/Data`; plus every real volume under `/Volumes/*` (apfs, hfs,
     exfat, msdos, ntfs). Skip `/System/Volumes/*`, snapshots, disk images if detectable.
   - Windows: every drive letter with nonzero total (fixed + removable), label via
     GetVolumeInformationW.
   - Linux: real filesystems only (ext4, xfs, btrfs, zfs, ntfs, exfat, vfat except
     /boot*); skip tmpfs/overlay/squashfs/loop/snap.
   - Free-space queries only (statfs / GetDiskFreeSpaceEx). Never walk directories.
6. **disk_io**: cumulative `read_bytes`, `write_bytes` summed over physical disks
   (gopsutil disk.IOCounters), additive top-level field. App computes rates.
7. **`GET /fleet?top=N`** on the agent, **loopback clients only** (403 otherwise):
   tailscale discovery cached 30s; fan-out to online peers' `/stats?top=N` in
   parallel (2.5s timeout); local host from the in-process full cache; 1s single-flight
   cache for the whole report. Same `aggregate.Report` JSON as `tailmon json`.
   (Mind the import cycle aggregate→agent: move DefaultPort to a tiny shared package.)
8. Version → 0.3.0. Schema stays 1 (all changes additive). Update README +
   docs/architecture.md efficiency contract.

## 2. Swift app (menubar/)

1. **Label numbers natively, no HTTP**: CPU% from `host_statistics(HOST_CPU_LOAD_INFO)`
   deltas, RAM used/total from `host_statistics64` (match gopsutil's darwin
   "available" semantics so label == dropdown), pressure from
   `kern.memorystatus_level`, GPU util from IOKit `IOAccelerator` →
   `PerformanceStatistics["Device Utilization %"]`. Menu closed: refresh label every
   5s (cost is a few syscalls). Peer `/health` probes for the letters: every 60s.
   Zero subprocesses, zero process scans while closed.
2. **Menu open**: `URLSession` GET `http://127.0.0.1:7020/fleet?top=10` every 2s, one
   in flight. Remove the `tailmon json` Process spawn entirely. If the local agent
   is missing/old (404), show a one-line Turkish error.
3. **Rates**: keep the previous (net rx/tx, disk_io r/w, sampledAt) per host → show
   `ağ ↓ ↑` and `disk o y` lines.
4. **Last-known disks**: persist per host+mount the last disk reading (UserDefaults,
   prune entries unseen for 30 days). If a live host lacks a disk it reported before
   (e.g. box D: asleep/disabled), show it with the stored values in the SAME style as
   other disks — no special "offline" styling (owner decision).
5. **Last seen**: persist last time each host was live; offline hosts render as one
   compact line at the bottom: dot, name, OS, "N gün/saat önce görüldü".
6. **New UI (mockup "Yeni")**, width 340:
   - Header: "Tailmon", "x/y canlı", age of data, `⋯` Menu: "Girişte başlat"
     (toggle via SMAppService.mainApp status), "Logu göster", "Tailmon'dan çık" (⌘Q).
     **Footer removed.**
   - Host card: dot, name (semibold 12), "OS · chip/GPU", uptime right ("23g 20s").
   - Two-column grid: left label column (22pt: CPU, RAM, GPU, disk letters C/D/E,
     "HD" on Mac, "/" on Linux); right: bars ~15pt tall, radius 4, with numbers
     INSIDE the bar: primary value left (white), secondary right (dimmed).
     CPU: "14%" | "yük 2.4". RAM: "18.9 / 32 G" | "swap 2.1 G" (swap as a lighter
     second segment). Disk: "1.2 / 1.8 T" | "598 G boş"; tooltip on the letter shows
     label + kind.
   - GPU = joined pair: util bar (15pt) "97%" | "RTX 5090 · 71°C · 548 W"; directly
     below, 1pt gap, VRAM bar (12pt) "28.4 / 32 G" | "fan %62"; Mac: "3.1 G" |
     "paylaşımlı bellek". One pair per GPU. No separate GPU-name row.
   - Small rates line, then "Süreçler" disclosure: collapsed shows "· <top proc> NN%";
     rows are bars whose fill = CPU share, name left, "16% · 149 M" right. Expanded by
     default only for the local host.
   - Agent RSS only as a tooltip on the host name.
   - Muted fill colors so white text stays readable; check legibility at 0-2%.
7. Keep WindowHeightFitter, AgentRegistry, DNS-label naming. Update tests/fixtures.
